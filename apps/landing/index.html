hermes web

put your Hermes agent on the web

packages

  • hermes-web-api — authenticated API server & management CLI
  • hermes.ts — TypeScript client
  • hermes-web-react — React hooks

quick start

# on the machine running your Hermes agent
npm i -g hermes-web-api
hermes-api keys create --name my-app \
  --scope chat:invoke --scope sessions:read
hermes-api serve

# in your app
npm i hermes.ts hermes-web-react

what it does

  • exposes a local Hermes agent as an authenticated web API
  • scoped API keys, restrictive by default
  • user identities with optional agent anonymity
  • typed client & React hooks, 100% test coverage
