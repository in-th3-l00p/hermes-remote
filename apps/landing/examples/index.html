Streaming token by token▍

A Telegram-style chat with streaming replies, markdown rendering, image attachments, reactions, and message edits. Sessions persist and the agent never learns who the user is. The entire conversation state is one hook:

chat.tsx✧
import { HermesClient, useChat } from "@in-th3-l00p/hermes-web-react";

const client = new HermesClient({ baseUrl: "http://localhost:8643" });

function Chat() {
  const { messages, streaming, send, edit, react, open, reset } =
    useChat({ client });

  return (
    <>
      {messages.map((m) => (
        <Bubble key={m.id} message={m}
          onReact={(emoji) => react(m.id, emoji)}
          onEdit={(text) => edit(m.id, text)} />
      ))}
      <Composer onSend={send} busy={streaming} />
    </>
  );
}

Run the API next to your agent

hermes-api

The server proxies your local Hermes agent to the web, with CORS, anonymous mode for demos, and Supabase user tokens for real products.

terminal✧
npm i -g @in-th3-l00p/hermes-web-api

hermes-api serve --anonymous \
  --cors http://localhost:5173 \
  --upstream http://127.0.0.1:8642 \
  --upstream-key $API_SERVER_KEY \
  --supabase-jwt-secret $SUPABASE_JWT_SECRET

Sessions & authentication

Supabase

Sign users in with Supabase (anonymous sign-in included) and their conversations persist server-side, scoped to their identity.

auth.tsx✧
import { createClient } from "@supabase/supabase-js";

const supabase = createClient(SUPABASE_URL, SUPABASE_ANON_KEY);
await supabase.auth.signInAnonymously();

const client = new HermesClient({
  baseUrl: "http://localhost:8643",
  tokenProvider: async () =>
    (await supabase.auth.getSession()).data.session?.access_token ?? "",
});

// each user only ever sees their own conversations
const sessions = await client.listSessions();
await client.deleteSession(sessions[0].id);

Plain TypeScript

no react

Stream straight from the typed client anywhere fetch runs.

stream.ts✧
import { HermesClient } from "@in-th3-l00p/hermes-web-ts";

const client = new HermesClient({ baseUrl: "http://localhost:8643" });
const session = await client.createSession();

for await (const event of client.sendMessage(session.id, {
  content: "hello!",
})) {
  if (event.event === "delta") process.stdout.write(event.data.text);
}
