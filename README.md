# hermes web

a project made for easily adding your Hermes agent to the web.

## hermes api

the possibility to communicate with your hermes agent in an authorized manner.

an API service that connects to your local Hermes agent instance, and exposes it to the web.

supports authentication and authorization

## hermes.ts

typescript library for consuming the hermes API

## react hermes

hooks that are making the integration of hermes api automatically
